Connect this phone

To keep sales and stock in sync across phones, this app uses a free Firebase project as shared storage. Set it up once, then paste the same 6 values on every phone you use.

One-time setup (do this once, on any computer):
1. Go to console.firebase.google.com → Add project
2. In the left menu, open Firestore Database → Create database → Start in test mode
3. Go to Project settings (⚙) → scroll to "Your apps" → click the </> web icon → register an app
4. Copy the 6 values shown (apiKey, authDomain, etc.) into the fields below
5. On your other phone, open this same file and paste the same 6 values
